## 2. 구조

### 2.1 장면 (FactoryScene)
- `WalkHost`: `setCameraDriver(d: CameraDriver | null)` — 있으면 OrbitControls·Navigator 를 끄고 매 프레임 `d.update(dt, camera)` 를 부름. 없으면 원래대로(마지막 궤도 시점으로 복귀).
- `setGhostWalls(on)` — 벽·가벽 재질 반투명 0.13 / 원래대로(조감 뷰용).
- `pickPlacement(sx, sy, far)` — 화면 좌표의 배치 id(18 m 안), 없으면 null.
- `worldOfPlan` / `planOfWorld` — plan 좌표 ↔ 월드 좌표(root 회전·반전 포함). 걷기 계산은 **plan 좌표**에서 하고 카메라만 월드로 바꾼다(회전·반전된 도면에서도 같은 코드).

### 2.2 순수 모듈 (`web/src/walk/`, vitest)
- `colliders.ts`: plan + 배치(+모델 크기·분류) → `{segs: {a,b,r}[], rects: {cx,cy,hw,hh,rot}[]}`.
- `collide.ts`: `collide(pos, radius, colliders, bounds)` — 선분·회전 사각형 밀어내기(2회 반복), 경계 안으로.
- `spawn.ts`: 시작 칸 찾기.
- `player.ts`: 입력(keys·joy·drag) + dt → 위치·yaw·pitch·흔들림 (참고 파일 animate 의 walk 분기).
- `zoneAt.ts`: 점이 든 구역(다각형 포함 판정).
- `minimap.ts`: 캔버스 그리기(2D context 주입, 테스트는 호출 기록 확인).

### 2.3 화면
- `web/src/pages/WalkPage.tsx` (`/walk`): AppShell(active `walk`, 머리글 = 도면 select · 품질), FactoryView(3D 고정) + 배치 객체(보기 전용) + 덮개 컴포넌트: `WalkOverlay`(시작), `WalkHud`(조준점·구역 배지·이름표·도움말 줄), `Minimap`, `WalkDetail`(상세), `TouchJoystick`.
- 키 입력은 입장한 뒤에만, 입력칸에 쓰는 중이면 무시. 페이지를 떠나면 카메라 드라이버 해제.
- 레일: `RailKey` 에 `walk` 추가, 메뉴 순서 `3D 공장 · 객체 · 체험 · 상황판 · 실행 · AI 챗봇`.
- 스타일: 참고 파일 색감(어두운 반투명 카드, 흰 글자) 을 기존 토큰으로. 이모지 금지(참고 파일의 🏠 링크는 넣지 않음), 아이콘 lucide.
